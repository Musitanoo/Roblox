## Observable outcome

The founder has selected the creative direction:

> Salvaged Frontier defines the world identity; Industrial Toy Defense imposes
> the readability discipline.

The remaining outcome is to convert that founder-level creative lock into a
production art lock without losing the truth boundary between taste,
preproduction evidence, Studio evidence, physical-device evidence and final
human approvals.

Before any production generation, compile a complete canonical visual
definition for every object in every territory and for every applicable state.
That canon must close the object's identity, one-second read, views,
proportions, construction, components, materials, semantic zones, transitions,
invariants, bounded freedoms, and explicit prohibitions. Blender is allowed to
reconstruct a locked canon; it is not allowed to decide what the object is.

Before canonicalization, a bounded precanonical layer may visualize the
functional brief through ChatGPT Web Images. It binds the selected
constitution, prompt, constraints, views, states, compiler and budget by hash.
Its output remains non-canonical until human selection and rationalization.

The result is complete only when a sixth, previously unseen asset can be built
from the frozen rules without inventing a new palette, shape grammar, material
class, camera convention, or gameplay-state language.

## Authority and integration

- This plan is the canonical art-direction execution plan.
- `art/` is the source of truth for artistic contracts and evidence.

- `tools/roblox-3d-asset/` remains the only production 3D pipeline.

  introduced.

## Non-negotiable coordinate contract

```text
Design and Roblox semantic axes:
X = width
Y = height
Z = depth

Blender axes:
X = width
Y = depth
Z = height

Mapping:
design [X, Y, Z] -> Blender [X, Z, Y]
```

Dimensions are named objects, never anonymous arrays. Every generated object
must be measured after construction and again after Roblox import. Grounded
objects require a base/feet bound at design Y=0 within declared tolerance.

## Truth and status rules

- `PASS` requires every applicable expected check and its evidence.
- Missing required evidence is never `PASS`.
- A process exit code alone is not proof; the expected result manifest must
  exist and declare the same successful run ID.
- `EXPLORATION` and `SELECTED` imply `productionApproved=false`.
- `FOUNDER_LOCKED` freezes the creative constitution but does not imply that
  any production asset is approved.
- `LOCKED` requires an allowed final territory, signed human selection,
  six object canons with complete hash-bound multimodal packets, complete
  provenance, Studio evidence, mobile evidence, and sixth-asset proof.
- Every result records tool versions, source hashes, run ID, inputs, outputs,
  checks, and explicit skipped checks.

## Comparison invariants

All territories use the same:

- five gameplay functions;
- named target dimensions and pivots;
- states and state applicability matrix;
- triangle and texture budgets;
- camera CFrames, vertical FOV, target point, aspect ratios and backgrounds;
- four Roblox lighting profiles;
- render and capture matrix;
- number of authored revision rounds;
- evaluator questions and randomized presentation order;
- Studio place, graphics settings and performance path.

Changing an invariant invalidates all affected comparison evidence.

## Milestones

### M0 — Doctor and staging preconditions

- Resolve Python and Blender through `scripts/r3d.ps1`.
- Record exact versions.
- Confirm the three publication variables are present without logging values.
- Confirm the active published Roblox place is exclusively staging.
- Record place identity only in local ignored configuration/evidence.

### M1 — Strict artistic contracts

- Install Art Direction, territory, calibration, camera, palette, materials,
  provenance, rubric, scorecard and evidence schemas.
- Reject unknown fields, non-finite values, missing gates and invalid state
  transitions.
- Add adversarial tests proving invalid contracts cannot pass.

### M2 — Provenance-backed references

- Collect 12–20 references per territory across shape, material, palette,
  modularity, VFX and anti-examples.
- Record creator, URL, capture date, rights, intended use and local hash.
- Unknown-rights references remain inspiration-only and are never redistributed.

### M2A — Canonical visual definitions

- Explore silhouettes and constructions while the territory is still a
  candidate.
- Compile one closed, schema-validated canon for every object x territory pair.
- Cover every applicable gameplay state from the same component hierarchy.
- Require redundant state cues that do not depend on color alone.
- Bind the GDD, retention doctrine, art-direction grammar, dimensions,
  materials, source description, and compiler by SHA-256.
- Keep the 12 non-selected canons as comparison candidates. The selected six
  Salvaged Frontier canons remain `CANDIDATE` until their complete multimodal
  packets receive explicit hash-bound human approval.
- Reject production generation before Blender unless every selected canon is
  `LOCKED + COMPLETE + APPROVED`.

### M2P — Precanonical visual exploration

- Compile gameplay briefs against the selected Salvaged Frontier constitution.
- Preflight hashes, stage scope, duplicate prompts and budget without quota use.
- Prepare a sanitized Web handoff with no automatic submission or fallback.
- Import downloaded bytes with conservative provenance.
- Allow human selection only as authorization to begin canonicalization.

### M3 — Three deterministic territory kits

- Build silhouette-first candidates using the shared calibration contract.
- Use exactly two bounded revision rounds after round zero.
- Produce isolated assets, manifests, geometry reports and standardized renders.
- Fail on bounds, pivot, budget, naming, material or camera mismatch.

### M4 — Golden Scene in Roblox

- Build one staging-only scene with R15 reference, grid, light/dark grounds,
  isolated kits, state rows, graybox baseline and groups of 30.
- Reuse identical MeshIds and texture IDs.
- Apply only script-writable Lighting properties; verify read-only properties by
  readback and configure them through an authorized Studio surface.
- Capture client/server console, hierarchy, bounds and screenshots.

### M5 — Mobile and perceptual evidence

- Test 15, 30 and 60 studs at normalized camera CFrames.
- Include 640x360, 960x540, 1280x720 and at least one narrow/portrait viewport.
- Run grayscale and CVD simulations.
- Use real baseline hardware for frame time, memory, loading and thermal proof.
- Treat eight-participant task tests as directional screening evidence, not a
  precise population estimate.

### M6 — Blind review and human selection

- Keep randomized label mapping outside reviewer score files.
- Require the exact complete hard-gate set.
- Validate score bounds, confidence bounds, reviewer independence and evidence
  references.
- Preserve pre-reconciliation disagreement.
- The blind study remains useful research but is not the authority used for the
  current strategic selection.
- The founder selected Salvaged Frontier explicitly and recorded rationale,
  rejected alternatives and the evidence boundary in a hash-bound decision.

### M7 — Freeze and transfer proof

- Freeze the selected Salvaged Frontier constitution and its positive/negative
  grammar.
- Build a sixth asset from the frozen contract only.
- Rebuild `turret_fast_v1` against the selected constitution and bind the
  current evidence digest.
- Final transfer approval remains pending until the founder approves the exact
  current selected-territory evidence package.
- Reopen the bible if the sixth asset requires an undeclared rule.

### M8 — Production pipeline completion

- Publish asset v1 to staging.
- Update v2 on the same package identity.
- Verify staged swap and rollback.
- Run benchmark evidence.
- Create the final `roblox-3d-asset` Codex skill only after every preceding
  required gate passes.

## Recovery strategy
