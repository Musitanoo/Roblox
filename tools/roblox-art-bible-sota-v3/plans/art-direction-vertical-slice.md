# ExecPlan — Art Direction Vertical Slice v3

## Goal

Convert the founder-selected Salvaged Frontier constitution into a fully
evidenced production art lock. Salvaged Frontier owns world identity;
Industrial Toy Defense contributes only the non-negotiable readability
discipline.

Before canonicalization, the bounded precanonical layer may visualize a
functional brief through ChatGPT Web Images. It binds constitution, compiler,
prompt, constraints, views, states and budget by hash; output remains
non-canonical until human selection and rationalization.

## Milestones

### M0 — Doctor and baseline

- Resolve Python, Blender and optional `r3d` wrapper.
- Record versions and baseline device identity.
- PASS only when every required tool is callable; otherwise BLOCKED.

### M1 — Contract closure

- Validate all Draft 2020-12 schemas.
- Run cross-file semantic validation.
- Run adversarial tests for every previously observed false PASS.

### M2 — Reference boards

- Maintain at least 12 provenance entries per territory.
- Embed no non-redistributable binary.
- Human art lead signs the approved cue extraction.

### M2P — Precanonical Web exploration

- Compile a closed functional brief into a stage-bounded request.
- Run zero-consumption hash, duplicate and budget preflight.
- Prepare a sanitized handoff with no automatic submission or fallback.
- Import image bytes with conservative provenance.
- Permit `HUMAN_SELECTED` only as authorization to canonicalize.

### M3 — Deterministic blockout compilation

- Build all five asset functions in their 13 applicable state pairs for all three territories.
- Normalize bounds and pivots from the calibration contract.
- Export per-asset/state GLBs and reports with hashes.

### M4 — Blender comparison matrix

- Run smoke matrix after each iteration.
- Run full matrix for candidates entering human testing.
- Validate vertical FOV by readback, not lens assumptions.

### M5 — Studio staging

- Publish/import through the existing r3d path.
- Stage assets under `ServerStorage.ArtDirectionAssetKit`.
- Configure protected Lighting preconditions manually in Studio.

### M6 — Golden Scene

- Build all seven zones.
- Validate states, dimensions, clone counts, cameras and shared IDs.
- No asset is accepted solely from Blender.

### M7 — Mobile and performance

- Device Emulator: framing, portrait/landscape, controls, streaming.
- Physical device: frame time, memory, thermal session, MicroProfiler.
- Compare against graybox with AB/BA order.

### M8 — Perceptual test

- Random labels A/B/C.
- At least eight pseudonymous task participants.
- At least two calibrated expert reviewers.
- Store blind map separately until submissions are sealed.
- Preserve the incomplete study as research; do not represent it as the
  authority behind the founder's strategic selection.

### M9 — Human selection

- [x] Founder selects Salvaged Frontier explicitly.
- [x] Record why Industrial Toy Defense remains a discipline rather than a
  co-equal identity.
- [x] Record both rejected alternatives and the evidence boundary.
- [ ] Bind final production approval only after the six selected canons and
  external evidence gates pass.

### M10 — Sixth-asset transfer proof

- [x] Preserve the v3.7 cross-territory transfer as historical evidence.
- [ ] Rebuild `turret_fast_v1` against the current selected constitution.
- [ ] Prove geometry, grammar closure, deterministic GLBs, state severity,
  front/back identity and mobile framing with the current hashes.
- [ ] Bind a human approval to Salvaged Frontier and the exact current evidence
  package SHA-256.
- Any invented palette, bevel family, damage grammar or material category is a
  bible defect.

### M11 — v1 lock

- Evidence index complete and all required gates PASS.
- Generate `art/art-lock.json` with canonical hashes.
- Mark art direction `V1_LOCKED` and productionApproved true.

## Non-negotiable failure rule

A score cannot compensate for a failed hard gate. An unavailable external system is BLOCKED/UNKNOWN, never PASS.
