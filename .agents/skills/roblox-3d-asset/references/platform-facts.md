# Platform facts

Platform behavior and limits are time-sensitive. Verify them against primary sources before changing the workflow or making a current claim.

Check:

- Roblox Creator Hub for Studio MCP tools, model specifications, texture rules, collisions, reimport, Packages, Open Cloud Assets, Scene Analysis, MicroProfiler, and hardware testing;
- Blender manual and Python API for the pinned Blender version;
- OpenAI Codex documentation for skill discovery and configuration.

Current workflow assumptions must remain capability probes, not promises:

- Studio MCP availability depends on the active Studio session.
- Package insertion and update behavior must be observed with the real staging asset.
- Studio simulation is not physical-device evidence.
- Cloud formats, size limits, permissions, and beta endpoints can change.
- Engine properties with inaccessible security cannot be required as proof.

Record the source URL, access date, and observed tool/version when a platform fact changes a gate or implementation.
